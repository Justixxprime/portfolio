# Icon guide

One UI family: Lucide (ISC licence), stroke width 1.5. One brand source: Simple Icons (CC0). Everything lives in one inline SVG sprite, `assets/icons.svg`, used with `<use href="assets/icons.svg#name">`. Decorative icons carry `aria-hidden="true"`.

Size scale: 12 px inline arrows, 14 px small controls, 16 px chips and links, 20 px fact lists, stats and nav, 24 px buttons and menu, 32 px and 48 px empty states and section marks. CSS classes: `ic-12`, `ic-14`, `ic-16`, `ic-20`, `ic-24`, `ic-32`, `ic-48`.

Exceptions to note: LinkedIn and Slack are taken from Simple Icons v13.21.0 because newer releases removed them. Paystack has no Simple Icons mark in the current release, so the Lucide credit card icon stands in for it.
